# 1. FastAPI ve React Stack Seçimi

Tarih: 2026-08-09
Durum: Kabul Edildi

## Bağlam (Context)
Performans takip sisteminin hızlı ve ölçeklenebilir bir backend'e ve modern, bileşen bazlı bir arayüze ihtiyacı var.

## Karar (Decision)
- **Backend:** FastAPI (Python) ve PostgreSQL.
- **Frontend:** React, Vite, ve Tailwind CSS.

## Sonuçlar (Consequences)
- **Artılar:** FastAPI ile hızlı API geliştirme, asenkron destek. React ve Tailwind ile modüler ve hızlı arayüz inşası.
- **Eksiler:** İki ayrı ekosistemin yönetimi (Python ve Node.js bağımlılıkları).
