# 12. Mimari Karar İndeksi

Repository taramasında `tier0/adr/`, `docs/adr/` veya başka bir dizinde
numaralı ADR belgesi bulunmamıştır. Bu nedenle indekslenecek mevcut ADR yoktur.

```text
ADR count: 0
Status: No ADR files currently present
```

Koddan çıkarılan stack, sentetik veri, OEE veya LLM kararları ADR belgesi
yerine geçmez ve burada hayalî ADR numarasıyla listelenmez. Gelecekte gerçek
ADR dosyaları eklendiğinde bu belge yalnız onların repository-relative link,
başlık ve `Accepted`/`Superseded`/`Deferred` durum indeksini taşımalıdır.
